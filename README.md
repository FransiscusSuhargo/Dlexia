# Aplikasi Hackaton Tim WEFindIT: Dlexia
Aplikasi Dlexia dirancang khusus untuk memudahkan penyandang disleksia dan ADHD dalam aktivitas membaca dengan 3 fitur utama:
## 1. Konversi teks dari gambar(OCR)
- Aplikasi mampu mengenali teks dari suatu gambar dan menampilkannya dalam font OpenDyslexic yang lebih mudah dibaca oleh penyandang disleksia.
## 2. Text-to-Speech(TTS)
- Aplikasi mampu membacakan teks yang terdeteksi dengan suara untuk mempermudah pengguna dalam memahami isi teks.
## 3. Rapid Serial Visual Presentation(RSVP)
- Menampilkan kata-kata dalam teks secara beruntun  dalam interval waktu tertentu. Teknik ini mampu meminimalisir gerakan mata sehingga mampu meningkatkan fokus dan kecepatan membaca, terutama bagi penyandang ADHD.


 ## Setup: 
 1. Clone repository 
 
 2. Masuk pada terminal di folder proyek(dlexia) dan masukan command berikut:
 - npm install 
 - npm run build
 - npx cap sync 

 3. Untuk menjalankan proyek masukan command: 
 - npx cap run android --target <device-id>
